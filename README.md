# AI-Powered Sports Engagement Content Agent

React.js + Vite frontend and FastAPI backend for generating Instagram-ready sports quizzes, polls, and challenges.

## Project Structure
- frontend/: React + Vite application
- backend/: FastAPI AI/RAG backend
- data/: Raw and processed knowledge
- chroma_db/: Persistent ChromaDB storage
- scripts/: Data ingestion scripts
- tests/: Project tests
